# Comptes de référence

Les comptes dont Daye veut s'inspirer, et les publications qui ont marché.

Ce fichier est rempli à la main, et c'est volontaire : Instagram ne laisse
pas lire les publications d'un compte qu'on ne possède pas sans un accès API
que personne n'a ici. Une référence notée à la main vaut mieux qu'une liste
automatique qui n'existe pas.

L'agent `veille-contenu` lit ce fichier. Plus il est nourri, plus il est
utile — et il reste utile dans six mois, quand on aura oublié pourquoi telle
vidéo avait marché.

---

## Format

```
### @nomducompte
Pourquoi : ce qu'il fait bien, en une ligne.
Audience : à qui il parle.

- [lien ou description de la publication]
  Format : Reel 45 s / carrousel / photo
  Accroche : la première phrase, mot pour mot
  Pourquoi ça marche : une ligne
  Transposable chez nous : oui / non, et comment
```
